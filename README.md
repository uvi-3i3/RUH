# رُوح — Ruh

A quiet Islamic spiritual sanctuary for daily prayers, Qur'anic reflection, remembrance, rational contemplation (*Burhan*), and Qur'anic signs (*I'jaz*).

## Scripts

- `npm run dev` — Start the development server on port 3000
- `npm run build` — Build the production bundle
- `npm run lint` — Run ESLint across the codebase
- `npm run cap:build` — Build and sync Capacitor native platforms
